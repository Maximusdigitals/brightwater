# Brightwater Zoo

A self-guided tour of a (fictional) 1931 zoo: fifty exhibits, one way round. Tap the animals, feed them, flip their signs, check the park map.
It gets dark very slowly. Then the gardens close.

- 29 real animals with real natural history, 10 original Spirit Grove residents with parody names (Pikachew, Catbust, Totoroar, Kuramuffin, Jiji-ish, Kyubey-gone, Ein-stein, Happy-ish, Luna-tic, Gon-zilla), 10 Quarantine Wing creatures from public folklore, and one final exhibit.
- After the tour: a three-lane escape runner. Swipe or use the arrow keys / WASD. Run mode unlocks on the gate once you've finished the tour.
- Vanilla HTML/CSS/JS, no build step, no network requests beyond this site. All art is SVG/canvas drawn in code; all sound is Web Audio.
- Fonts: Bungee, Young Serif, Archivo, Reenie Beanie, Courier Prime (SIL OFL 1.1, licences in `/fonts`).

Content note: horror imagery, one loud jump scare, no strobe lights.
